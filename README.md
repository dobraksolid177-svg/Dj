# ™®RD♥ DJ Studio — V3 FINAL

Premium browser DJ/audio remix studio based on the supplied Luxury V2 project.

## Files
- `index.html` — UI and structure
- `style.css` — luxury responsive design
- `script.js` — browser Web Audio DSP, playback, waveform, presets and WAV export
- `vercel.json` — Vercel static configuration
- `package.json` — optional local dev scripts

## Deploy to Vercel
1. Upload all files to a GitHub repository.
2. Import the repository into Vercel.
3. Framework Preset: **Other**.
4. Build Command: leave blank.
5. Output Directory: `.`
6. Deploy.

No database or API key is required. Audio is processed locally in the browser.

## Included
- Luxury dark/gold responsive UI
- Audio loading and drag/drop
- Waveform timeline and seeking
- Play, pause, stop and preview
- Club / Night / Hard / Chill presets
- Bass / Treble / Presence
- Echo / Reverb / Stereo Width
- Drive / Energy / Speed / Master
- DJ Drop / Stutter / Reset FX
- Real-time meter
- WAV master export
- Mobile-friendly layout

Use only audio you own or have permission to edit.
